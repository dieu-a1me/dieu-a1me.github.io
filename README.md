## Preview locally
1. Extract the ZIP file.
2. Open the `cybersecurity-data-analyst-portfolio` folder.
3. Double-click `index.html` to open it in a browser.

No build tools are required.

## Publish with GitHub Pages
1. Sign in to GitHub as `dieu-a1me`.
2. Create a new public repository named `dieu-a1me.github.io`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish the site. The expected address is `https://dieu-a1me.github.io/`.
